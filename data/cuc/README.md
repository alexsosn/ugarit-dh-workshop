# Bundled CUC teaching snapshot

`cuc.parquet` is the line-level teaching snapshot consumed by
`workshop_tools.loader`. It contains 7,616 rows and 279 KTU tablets exported
from the Copenhagen Ugaritic Corpus through the public `AlexWalhai/CUC`
HuggingFace dataset.

Source project: `DT-UCPH/cuc` (CACCHT). Underlying corpus licence: CC BY-NC
4.0; educational/non-commercial use only, with attribution. The snapshot is
bundled so every notebook can run from a fresh repository clone without a
runtime corpus download.
