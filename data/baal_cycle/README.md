# Reviewed Baal Cycle annotation

This directory contains the reviewed CUC token annotation used by
`notebooks/3c_divine_name_networks.ipynb`:

- `KTU 1.1.tsv` through `KTU 1.6.tsv`
- `onomastic_gloss_overrides.tsv`

Source: Copenhagen Ugaritic Corpus (`DT-UCPH/cuc`), snapshot from commit
`9e9ebd38cea2266e3cba6f2d94383fed1184f55a` (2026-07-06). The underlying CUC
material is CC BY-NC 4.0 and requires attribution. These files are bundled so
the teaching notebook runs from a fresh repository clone without a second
checkout or a developer-machine path.
